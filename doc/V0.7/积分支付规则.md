# 积分支付规则（业务精简版）

> 面向业务侧（产品/运营/客服）的精简版，**只讲规则、不讲实现**。完整版见 `doc/V0.7/PRD-订单支付规则与积分叠加迭代-V0.7.md`。
>
> 本文分两部分：**一、现有规则**（V0.7 前就有的）；**二、V0.7 新增规则**（积分批次多选叠加）。

***

## 一、现有规则

### 1. 四种订单类型

| 类型   | 下单入口            | 积分可用范围   | 优惠券     | 电影次卡      |
| ---- | --------------- | -------- | ------- | --------- |
| 实物商品 | 购物车/详情页         | 全部 5 种积分 | 未实现，不考虑 | 不支持       |
| 蛋糕   | 蛋糕详情页（不进购物车）    | 全部 5 种积分 | 未实现     | 不支持       |
| 电影票  | 电影 H5 选座（不进购物车） | 全部 5 种积分 | 不支持     | 支持（与积分互斥） |
| 虚拟商品 | 购物车/详情页         | 全部 5 种积分 | 不支持     | 不支持       |

> 四种订单**两两不能合并结算**；虚拟商品一次只能下一个 SKU。

### 2. 积分换算

**后台可配**（默认 1 积分 = ¥0.01，即 100 积分 = ¥1）。实际比例由后端「积分换算」配置决定，不写死。

### 3. 支付方式（随积分使用情况变化）

- 不用积分 → **现金支付**
- 积分够付全额 → **积分支付**（直接成功，跳过收银台）
- 积分不够付 → **积分 + 现金组合**

### 4. 电影次卡（仅电影票）

- 与积分**互斥**（二选一，选积分就清次卡，反之亦然）
- 抵扣"多不退少补"：每次抵 `单次上限` 与 `票价` 的较小值

### 5. 积分抵扣（V0.7 前：单选）

- 一个订单只能用**一张**积分批次
- 抵扣 = 该批次余额 与 可抵金额 取小

## 二、V0.7 新增规则：积分批次多选叠加

### A. 叠加核心

#### 1. 核心变化

**单选 → 多选**：一个订单可同时用**多张同类型**积分批次抵扣。

- 之前：账户里两张通兑积分，一单只能用一张
- 现在：两张通兑可**叠加**一起抵

#### 2. 叠加规则（什么能叠加、什么不能）

- ✅ **可叠加**：积分**类型相同 且 适用范围相同（规则完全相同）**
  - 两张通兑（都全场通用）→ 可叠加
  - 两张同范围的品牌积分 → 可叠加
- ❌ **不可叠加（互斥）**：类型不同 或 范围不同
  - 通兑 vs 指定商品积分 → 互斥
  - 两个品牌积分但适用品牌不同 → 互斥
- **交互**：选中一张后，不同类型的批次自动**置灰不可选**，同类型的可继续勾选叠加——用户选不出互斥的组合。

#### 3. 消耗顺序

多张叠加时，**先扣最快过期的批次**，依次填满本单抵扣额——保护临期积分不浪费。

#### 4. 抵扣金额

叠加后总抵扣 = `选中批次余额合计` 与 `本单可抵金额` 取小。

#### 5. 推荐组

标「推荐」角标的是后台算出的**最优叠加组合**——本单能消耗最多积分的那一组（同类型同范围，整组都标），引导用户选这一组叠加最优。

### B. 分配细节

#### 6. 消耗与分配细节

**逐卡扣减**：选中多张卡时，不平均消耗，而是先扣完第一张再扣第二张。

**消耗顺序**：
- 优先消耗快过期的卡（按有效期升序）
- 若有效期相同，随机选一张优先消耗

**分配公式**（多商品订单）：
- 某商品分配的积分 = 该批次总消耗 × (该商品价格 ÷ 订单所有适用商品总价)
- 第一张卡按比例分配到各商品 → 不足再按比例消耗第二张卡 → 类推

> 举例：订单含商品X（¥60）和Y（¥40），批次A余额 ¥50 → X分配 ¥30（3000积分）、Y分配 ¥20（2000积分）。若批次A余额只有 ¥30 → X分¥18、Y分¥12，不足部分由批次B按同规则补充。

### C. 各订单表现

#### 7. 各订单类型的叠加表现

| 订单              | 可用积分   | V0.7 叠加               |
| --------------- | ------ | --------------------- |
| 实物商品            | 全部 5 种 | 同类型同范围批次可叠加，跨组互斥     |
| 蛋糕 / 电影票 / 虚拟商品 | 全部 5 种 | 同类型同范围批次可叠加，跨组互斥     |
| 电影票             | —      | 叠加不影响**积分与次卡互斥** |

### D. 提示

#### 8. 覆盖提示

已选卡组的积分余额**足够覆盖本单全部金额**时，继续勾选其他卡会弹出提示："当前已选积分已可覆盖本单金额，继续勾选不会额外扣减"——不阻断，仅提醒。

#### 9. 拆单（规则与提示）

- **拆单规则（何时触发）**：订单内多个商品的积分适用范围不一致（如一个仅适用品牌积分、一个仅适用通兑），无法用同一批次覆盖全部商品。
- **拆单提示（如何展示）**：选中某批次后，对**不适用该批次**的商品，在该商品行展示提示——**浅灰底 + 红字**，文案「该商品不适用所选积分，建议此商品分开下单以便使用积分」。不阻断下单，仅引导。

### E. 售后

#### 10. 退款规则

- **订单持久化**：每张卡实际消耗的积分数/金额必须存入订单数据，作为退款依据
- **精准原路退回**：全额退款 → 哪张卡实际扣了多少就退回多少；部分退款 → 直接读取订单存储的「该退款商品对应的各卡实际抵扣金额」精准退回（不同商品可能由不同卡抵扣，不能简单按总订单比例算）
- **余额恢复**：退款到账后，对应批次的可用余额恢复

## 三、V0.7 没动的规则（保持不变）

- **优惠券**：功能未实现，整体不考虑（组合支付统一"积分→现金"）
- **QQ 号充值**：随 V0.62 废弃，虚拟商品直充仅手机号
- **电影次卡与积分互斥**
- **纯积分支付跳过收银台**
- **虚拟商品充值成功不可退**、进页强制风险提示
- **蛋糕订单**：地址只读（蛋糕叔叔提供）、数量固定、蛋糕叔叔配送
- **四种订单两两不可合并结算**
- 积分换算比例由后台配置（默认 1 积分 = ¥0.01），不写死
